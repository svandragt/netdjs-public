# netdjs-public

The public issue tracker and help wiki for NetDJs, a directory of NetDJ events.
The application code is private, so this repository holds no code.

## Report a bug or request a feature

Open an [issue](https://github.com/svandragt/netdjs-public/issues).
Describe what you expected, what happened, and the page you were on.

## Get help

Read the [wiki](https://github.com/svandragt/netdjs-public/wiki).
